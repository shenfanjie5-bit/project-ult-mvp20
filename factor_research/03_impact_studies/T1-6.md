# T1-6 — 筹码获利盘比例 + 集中度 (CYQ Winner_Rate + Chip_Concentration)

**裁决：CONDITIONAL** · 把握 med · 实施优先级 med

### 目标轴
capital_sentiment（主）; 潜在 priced_in_discount 辅助（winner_rate反转分量）

### 系统已有?
partial — cyq_perf已在 providers.py::chip_distribution 注册，但零个dp_id节点被路由到任何 score_target；winner_rate/集中度字段均未进入聚合器。无等价运行中信号。

### 正交性
相对现有六轴提供中等正交信息。(1) vs capital_sentiment（当前仅L7.flow.active_inflow主力净流入）：CYQ捕获【持仓成本结构】，active_inflow捕获【当日订单方向】，两者测量不同现象——相关系数估计<0.3，独立性可接受。(2) vs priced_in_discount（L6.priced.run_up + crowdedness）：winner_rate与run_up存在中度相关（股价上涨→获利盘同步增加），相关系数约0.4-0.6；但run_up仅记录20日价格涨幅（动量），winner_rate还包含历史所有持仓成本分布（更长的历史成本记忆），两者不完全等价。集中度（Chip_Concentration）与crowdedness（换手率百分位）相关约0.2-0.3，基本正交。(3) vs fundamental/valuation：无直接关联。总结：winner_rate提供中度正交信息（需警惕与run_up的部分重叠），集中度提供较高正交信息。

### 双计风险
中等风险（仅针对winner_rate）。winner_rate随价格上涨而自然升高，与现有priced_in_discount中的L6.priced.run_up（20日价格涨幅）存在共线性（股价上涨20%→获利盘比例同步升高）。若winner_rate接入capital_sentiment（看空）、run_up同时在priced_in_discount（看空），两者对同一价格上涨事实各罚一次——双计同一价格上涨的代价而非两个独立事实。缓解方案：winner_rate信号中性化掉run_up的影响（回归残差），或将winner_rate明确仅接入priced_in_discount（替代run_up的成本维度）而非capital_sentiment。集中度因子（Chip_Concentration）无此双计风险。

### 方向
条件正确，但需明确：(A) winner_rate高值（>70%获利盘）→ 大量持仓者处于盈利，供给压力大 → 【看空/负向信号】。在capital_sentiment轴（+资金流入=正方向），需以反向编码接入：low winner_rate (大套牢盘) → capital_sentiment正向（抛压小，供给受限）；high winner_rate → capital_sentiment负向（供给压力）。这与"反转"逻辑一致，方向可正确表达，但与capital_sentiment轴的直觉（资金主动流入）语义差异较大，更自然地属于priced_in_discount辅助轴。(B) Chip_Concentration高值（低分散，主力控盘）→ 价格稳定，上涨阻力小 → 【看多/正向信号】——capital_sentiment正向，方向完全正确，语义也自然（高集中=机构锁仓=资金稳定）。

### A股有效性/陷阱
A股实证有效，但有重要限制。(1) winner_rate：华创证券"双重筹码集中选股策略"报告（hcquant.com）：筹码集中度+获利盘过滤组合有超额收益；06_liquidity_micro.md #8记录单因子IC~0.04（低），与动量交叉后IC 0.07-0.09；5-21日反转预测效果最强，+60-90日系统本身已知反转方向与此吻合。(2) Chip_Concentration：独立IC约0.02-0.04，配合获利盘使用更稳定。【陷阱】：①cyq_perf数据从2018年起才可用，训练窗口相对短；②CYQ模型基于历史场内成交推算，大宗交易（机构过桥）不反映在内，机构主导大盘股信号偏弱；③涨跌停日筹码结构扭曲（封板量比小→CYQ误认为成交量缩减而更新慢），A股限价机制是系统性干扰；④T+1限制下，高获利盘卖压在次日才能释放，日内信号有1TD滞后偏差；⑤ST股筹码模型基础已扭曲（长期跌停/停牌）需剔除；⑥数据采集限量6000条/次，需分批拉取，存在数据工程负担；⑦大盘蓝筹（机构主导）信号远弱于中小盘，系统以A股全市场覆盖，需市值分层验证。

### 周期契合
winner_rate：5-21TD反转信号，与系统2-4周甜区（+10d rankIC+0.11核心窗）高度吻合。但需注意：系统已知+60-90日反转（普涨市低质量反弹），而winner_rate在大涨后极高（>80%），此时按负向看空与系统+60-90d反转方向一致，不冲突。Chip_Concentration：10-63TD中期建仓完成信号，短-中均覆盖，horizon适配性中等偏好（偏中期，short权重0.40对capital_sentiment，但集中度信号本身衰减慢，不完全是2周信号）。总体：winner_rate horizon契合好（★★★），集中度中等（★★）。

### 机构适配
中等适配。A股机构化加速（2024年外资+公募持流通市值超30%），但CYQ筹码模型基于历史场内成交推算，机构持仓部分通过大宗交易或场外换手，不完全反映在场内筹码分布中——这意味着CYQ更多反映散户/游资成本结构。对"机构为主市场"（系统描述），北向资金（hk_hold）和主力净流入（active_inflow）比CYQ更直接代理机构行为。不过散户持仓成本结构本身是A股特有的独立信息维度，即使在机构化市场中，散户的套牢与获利比例仍通过行为性供需影响价格，对机构判断交易时机有参考价值。适配度：中等（非机构行为的直接观测，而是散户供需的结构性测量）。

### 接入设计
【接入设计（CONDITIONAL）】：推荐分两个节点分开接入，使用不同路由策略。

(A) Chip_Concentration（集中度，优先接入）：
- 新增 dp_id: L7.chip.concentration
- score_target: capital_sentiment
- 公式: CHIP_SPREAD = (cost_85pct - cost_15pct) / cost_15pct; signal = tanh(-(CHIP_SPREAD - SPREAD_MEDIAN) / SPREAD_SCALE)，高集中（低SPREAD）→正值
- 中性化: 行业内 zscore（申万二级行业），市值加权
- 归一: tanh，[-1,1]
- 权重: 0.15（capital_sentiment内部权重，相对active_inflow），参考short-horizon weight 0.40中分配
- PIT安全: cyq_perf按trade_date读取，使用t-1日数据（避免当日尾盘数据未完成），无PIT泄漏风险

(B) Winner_Rate_Factor（获利盘，有条件接入）：
- 建议路由: priced_in_discount（而非capital_sentiment），避免与run_up语义重叠
- 新增 dp_id: L6.priced.winner_rate（或L7.chip.winner_rate，取决于策略方向）
- 公式: WR_signal = tanh((winner_rate - WR_MEDIAN) / WR_SCALE)，取负向（高获利盘→负向，减分）；交叉截面rank中性化（行业内）
- 条件: 必须先做行业中性化后再与L6.priced.run_up做正交化处理（残差化），否则双计风险。或者：将winner_rate仅作为run_up的增强版（若已有run_up信号，winner_rate提供补充的成本维度），给予0.1的小权重
- 排除条件: ST股剔除，涨跌停当日数据截断，上市不足210个交易日的新股剔除（CYQ窗口不足）

整体：先接集中度（清洁信号，无双计），再条件性接winner_rate（需正交化处理）。

### 负面情形
1. 【winner_rate与run_up双计】：若不正交化，股价上涨时run_up（priced_in罚分）和高winner_rate（capital_sentiment负信号或priced_in补充罚分）同时触发，对同一价格上涨双重惩罚，导致系统性偏向看空上涨股。这是最严重的失效模式。

2. 【大盘股信号退化】：A股机构主导大盘股（如沪深300成分股）中，机构通过大宗交易换手，CYQ场内筹码分布不完整。系统若覆盖大市值股为主时，信号退化至IC≈0.01-0.02，噪声超过信号。

3. 【涨跌停日集中扭曲】：连续涨停板（A股特有，尤其小盘题材股）期间成交量极小，CYQ筹码更新极慢，导致winner_rate在连板后数日内仍显示"低获利盘"（实际大量持仓者已浮盈），系统据此给出"低套牢→看多"的误判，恰好在最危险的连板高位发出错误信号。

4. 【2024年后机构化加速导致因子衰减】：散户占比持续下降，CYQ信号对价格的解释力随之下降，历史IC可能高估未来效果。

5. 【集中度在行情转折点失效】：主力出货时会主动分散成本（分批卖出），导致集中度由高转低，但此时价格可能还在上涨（出货期）——集中度下降与短期价格下跌之间存在时滞，可能误判为"集中度仍高=看多"。

### 裁决理由
CYQ因子族提供A股特有的持仓成本结构信息，对capital_sentiment轴（当前极度空置，仅一个active_inflow节点）有实质性填充价值，且数据已在系统provider层注册。但接入需满足两个条件方能保证净正面：

(1) 优先且相对安全接入的是Chip_Concentration（集中度）：无双计风险，方向明确（高集中=机构锁仓=正向capital_sentiment），2-4周horizon适配，行业中性化后IC约0.02-0.04，在capital_sentiment轴几乎空白的现状下即便小IC也是净增益。建议新增dp_id L7.chip.concentration，直接接capital_sentiment，权重0.15。

(2) Winner_Rate_Factor条件接入：必须先完成与L6.priced.run_up的正交化处理（在行业内中性化后取winner_rate对run_up的线性残差），否则双计风险明显。残差化后，winner_rate的独立信息分量（超出价格动量已解释部分的成本记忆效应）可作为priced_in_discount的补充信号，权重0.10，而非独立接入capital_sentiment。

如果无法做正交化，winner_rate接入capital_sentiment负方向的语义冲突（资金流轴放了个反转信号）和双计风险合并，则该子因子单独为NEGATIVE；只有集中度因子可独立接入（POSITIVE）。
