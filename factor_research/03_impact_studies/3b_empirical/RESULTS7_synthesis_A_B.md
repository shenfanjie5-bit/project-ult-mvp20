# Phase 3b 收口 — Agent A（gate 避损）+ Agent B（真分扩日期/OOS）联合结论

> 两个隔离只读 agent 并行产出。A=`RESULTS5_gate.md`，B=`RESULTS6_realbase.md`。本文做 A+B 的对账与最终收口。

## 1. A 与 B 表面"矛盾"，实则测的是两层 —— 这是最关键的方法论收获

- **A（决策层/P&L）**：在 2026 真 base_score 上，坏 regime 抑制 BUY **避损 +3.9pp(+10d)/+4.4pp(+20d)**。
- **B（排序层/IC）**：在 7 日期真分上做 regime overlay 的**样本外 IC 无改善**；并指出 **rank-IC 对正向缩放不变 → "降权门控"对 IC 完全不可见**，只有 sign-flip 能动 IC，而 sign-flip **有害**（+20d Δ=−0.10）。

**对账**：二者不矛盾，**测的是不同层**。门控=降权（scale）操作 → IC 看不见（B 证），但真实 BUY 组合盈亏看得见（A 证 +4pp）。
> **⇒ 模型的问题与解法都在【决策/P&L 层】，不在【IC/排序层】。** 这解释了最反直觉的一幕：2026-03-09 那天 **IC=+0.238（排序很准）但 BUY 组合亏 −4.97%**——IC 测排序、不测绝对盈亏；普涨急跌里"相对最优"的票也整体下跌。**用 IC 验证 regime-gate 是错的工具；必须用 BUY 组合实际收益验证。**

## 2. 真分（非 proxy）证实 regime-脆弱性，跨 2024-2026

B 重算了 4 个历史日期真 base_score（250 股分层样本，因全量 172min/日不可行）+ 3 个缓存 = **7 日期跨 regime 面板**：
- 真分 +10d/+20d IC 从 **+0.278/+0.240**（2024-01 恐慌底，跌/高波）到 **+0.065/−0.186**（2024-09 急涨，涨/高波）。
- `corr(IC, trend60) ≈ −0.4~−0.5`：**跌市 IC 更高**（反转更有效），与 proxy 结论一致——**但现在是真分、跨多年**。
- ⚠️ 但**简单 trend/vol 桶不能干净切分 IC**：两个跌市日 IC 反号、同为"涨/高波"的日 IC 从 +0.11 到 −0.19 → **regime 信号本身太粗**。

## 3. 两个 agent 一致的三条结论

1. **避损，不反号**：A"反号数据不支持"、B"sign-flip 有害(−0.10)" → **只降权/回避，绝不反向择时**。
2. **简单 regime 不够，要加 IC-衰减 meta-regime**：A"门控需【坏 regime + 模型近期 IC 衰减】双条件，否则好年误杀（全样本 −0.3pp）"；B"trend/vol 太粗，需 down×high-vol 交互 + 换手/M2 + 模型自身 IC-衰减"。两者独立收敛到**同一处方**。
3. **必须用 P&L/决策层指标验证**（BUY 组合收益、避损），不是 IC。

## 4. 可行性与成本（B 实测，给后续定盘）

- 真分重算 **~6s/股**（瓶颈=live tushare 单 token 串行；DockCase 缓存只供 by-symbol 财务，不供价/流/融资的截面历史）。全量 1641 股 **~172min/日不可行**；250 股样本 4 日并发 ~26min 可行。
- **更充分的研究需要**：~80+ 月度日期跨牛熊（须**离线预缓存**价/流截面以绕开 tushare 串行，否则 ~35h）+ **更聪明的 regime 分类器**（交互项 + 换手/M2 + 模型 IC-衰减 meta）+ **walk-forward OOS** + **只降权**。

## 5. 最终收口（A+B 后，证据完整）

> **"更优模型"的可落地形态 = 在现有 dual-axis 之上加一层【决策/P&L 层的 regime 风控闸】**：当【高波 risk-on regime + 模型近期 IC 衰减】同时成立时，**降低短周期信号权重 / 抬高 BUY 阈值**（少做、持币），保护真实盈亏；**不反号、不试图择时押注**。
> - 已证：避损在真分 2026 值 +4pp；问题（IC 随 regime 翻转）在真分跨 2024-26 成立。
> - 已证伪：用 IC 验证门控、用 sign-flip 反号、用单一 trend/vol regime ——都不成立。
> - 这一层是**风控/置信闸**，不是新 alpha 因子；与"补最正交的基本面惊喜(SUE/预告快报)"互补但独立。
> - 落地前的完整验证是一个**有明确成本的子项目**（B 给了路线），不是一行开关。
