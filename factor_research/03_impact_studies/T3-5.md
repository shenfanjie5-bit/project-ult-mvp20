# T3-5 — MAX effect 极端日收益均值（MAX5）

**裁决：CONDITIONAL** · 把握 med · 实施优先级 med

### 目标轴
risk_discount

### 系统已有?
none ——现有 risk_discount 节点全为基本面/资金流/公司治理风险：L8.cap.crowdedness(换手百分位) / L8.cap.liquidity_short / L8.cap.outflow_cut / L8.cap.short_increase / L8.fin.{cash_ar,debt_pressure,eps_downward} / L8.op.{cost_overrun,inventory_glut} / L8.gov.*。均不捕捉日收益分布的极端正偏特征。priced_in_discount 侧的 L6.priced.run_up 是方向性动量（20d价格涨幅）、L6.priced.crowdedness 是换手历史百分位，二者均非"极端正收益的统计矩"。MAX5 = mean(top-5 daily returns in past 20d) 是全系统的空白信号。

### 正交性
对现有六轴有新增正交信息。(1) vs risk_discount现有节点：现有L8节点捕捉基本面风险(财务/运营/治理)和资金流风险(筹码拥挤/出逃/做空)，均不含价格收益分布信息；MAX5捕捉的是散户彩票偏好形成的定价偏差(behavioral premium)，驱动机制完全不同。(2) vs priced_in_discount：run_up是20d方向性涨幅(市场已定价该方向)，MAX5是极端日收益的均值(散户愿为罕见暴涨支付溢价)；两者相关但不重叠——MAX5高的股票不一定有大run_up(可能是高频小涨但偶有10%板)，run_up高的股票不一定有高MAX5(可能是连续2%稳涨)。(3) vs capital_sentiment/funding_score：资金流入是当前资金方向，MAX5是历史极端收益的统计矩，二者独立。相关性最高的是 L6.priced.crowdedness(换手拥挤)和 L6.priced.run_up，Spearman相关估计约 0.3~0.5，远低于1，保持正交增量。

### 双计风险
低。最易混淆的两对：(1) L6.priced.crowdedness vs MAX5——前者是换手量历史百分位(交易活跃度)，后者是价格收益率分布的极端正尾均值，不同统计量，同一只股票可以高换手但无极端日收益，或低换手但多次涨停；(2) L6.priced.run_up vs MAX5——run_up是累积方向性动量，MAX5是极端单日收益的均值，两者实证相关约0.35(文献)，仍有大量独立变异。系统内已有因子均针对基本面/资金流，无任何节点从"收益率分布形态"角度计量风险，双计风险极小。警示：若未来同时接入 LIMIT_FREQ(涨跌停频率)，两者会有约0.6相关度，届时需选一或降低权重。

### 方向
方向正确。高MAX5 → 散户彩票偏好溢价 → 股票被高估 → 预期未来收益低 → 应作为 risk_discount(减分项)。在本系统框架：risk_discount是减项，节点以正magnitude存储后被减去；MAX5高=坏信号=大magnitude=大罚分，符合 −risk 逻辑。反向：低MAX5=无彩票溢价=magnitude小=对分数贡献中性，不额外奖励。方向无逆转风险：即使A股机构化加深，彩票偏好驱动的定价偏差短期内不会反号(机构化使该效应轻微衰减但未反转，2023-2024研究确认)。唯一方向陷阱：连板股在极短期(1-3日)内确有追高动量，但这是2周以内的噪声，2-4周持有期的系统已超过该动量窗口，反转负向成立。

### A股有效性/陷阱
实证有效且经多篇独立文献交叉验证。(1) Bali-Cakici-Whitelaw(2011) JFE 原始发现美股MAX负向显著；(2) Wang Liyao EFMA 2025: 中国A股2000-2022年，因子MAX策略风险调整收益8.50 vs 股票MAX策略5.47，超额收益约3pp；(3) SCIRP Theoretical Economics Letters 2023: A股MAX效应显著负向(方向确认)；(4) Wiley JFM 2025: 彩票偏好与偏度风险溢价，A股确认。IC方向在中性化后仍显著，IC均值估计约-5%至-8%范围。A股特有陷阱及处理: ①涨停截断(10%主板/20%科创创业板/30%北交所/5%ST) → 右删失使MAX值被系统性低估，用5日均值(而非单日MAX)更稳健，且要分板块标准化；②T+1制度下，信号形成后T+0无法出空，须T+2后入场以避免1-3日连板动量干扰；③ST股需强制剔除(极端收益受5%制度影响，非真实彩票信号)；④因子拥挤风险：MAX效应在A股量化圈已有一定认知，机构化加深可能导致α衰减，建议持续监控IC滑动衰减；⑤小盘效应：小市值股MAX高，需严格市值中性化，否则因子实为小盘溢价而非彩票溢价。

### 周期契合
与系统2-4周窗口契合度较高。MAX5以过去1个月(约20交易日)日收益数据构建，预测效力集中在1-4周，与文献中A股短期彩票溢价反转窗口一致(2-4周是反转高峰，4-8周衰减，8周以上无效)。系统已知量化核心窗口+10d rankIC最强(+0.113)、+15d/+20d次之、+30d弱、+60-90d反转——MAX5是负向因子(高MAX→低未来收益)，其预测力也集中在2-4周内，与系统框架对齐。注意：MAX5是月末截面更新信号，若系统按周更新，需确保数据滚动计算；月频更新的信号在第3-4周可能有轻微衰减但仍显著。

### 机构适配
对"机构为主市场"适配度中高。机构逻辑：①公募/险资持仓系统普遍剔除高频涨停连板题材股，MAX高者是机构主动回避标的；②北向资金(沪深港通)几乎不参与主板连板游戏，流入方向与低MAX负相关，机构资金本身就在"做空MAX效应"；③量化机构大量使用波动率/偏度类因子，MAX5被机构量化广泛纳入，该因子反映的是机构与散户定价分歧的结构性机会。风险：A股散户占比55%+，散户彩票偏好持续驱动高MAX溢价，但随机构化(公募规模扩大、北向资金增加)效应略有收敛；目前A股散户结构短期不会根本改变，因子机构适配性稳定。

### 接入设计
1. dp_id新增: L8.cap.max_effect (需新增，不与现有L8节点冲突) 2. score_target: risk_discount (已有轴，直接接入) 3. 计算: MAX5_i = mean(top-5 daily log returns in past 20 trading days)；分板块处理上限(主板保留≤10%日收益，科创/创业板保留≤20%，北交所≤30%，ST股剔除)；原始值取负后用于打分方向(高MAX5→高罚分) 4. 数据源: tushare daily(前复权收盘价) + stk_limit(识别涨停日) + limit_list_d(备用)；PIT安全：daily历史数据按trade_date AS-OF过滤，无前视风险 5. 中性化: 行业中性化(申万一级)+市值中性化(ln market_cap)，残差法；市值中性化至关重要(小盘自然高MAX) 6. 归一: 截面z-score后tanh(z/1.5)压缩至(-1,1)，作为magnitude；magnitude = abs(signal)，direction="negative"(彩票溢价=风险=负方向) 7. 权重建议: 初始confidence=0.75(数据质量稳定但因子拥挤风险存在)，base_weight建议0.8-1.0(与L8.cap.*节点同量级)；short_horizon_mix=0.5偏重短期 8. PIT安全性: 高——全部依赖历史日收盘价，无财报PIT泄漏风险；月末计算，T+2入仓，无未来信息

### 负面情形
1. 连板追高陷阱：信号形成后1-3日内有短期动量(连板惯性)，若系统在T+0建仓会短暂承受反向损失，建议T+2后执行；2. 板块差异标准化失败：主板/科创/创业板涨停上限不同(10%/20%/30%)，若不分板处理，主板MAX5系统性低于科创板，造成错误截面排序；3. 牛市单边上涨期失效：2024年9月后急涨行情中，低MAX、低波动股票跑输(全市场普涨，彩票溢价暂时消失)；系统R-7宏观机制尚未激活，这种失效期无法动态关闭因子；4. 小盘效应残留：若市值中性化不严格，因子实测到小盘溢价而非彩票溢价，在小盘成交量枯竭期(如2024年初A股流动性危机)产生错误正向信号；5. 因子拥挤：A股量化机构广泛使用波动率族因子，MAX5被多机构同时多头/空头时，异常平仓会产生尾部冲击；建议监控因子自相关和拥挤度指标。

### 裁决理由
MAX5提供系统当前完全缺失的信号维度：价格收益率分布极端正尾(彩票偏好溢价)。现有9个risk_discount节点全为基本面风险，无任何收益分布统计量；priced_in_discount的run_up/crowdedness也是方向/换手代理，不是分布矩。实证支持稳健：多篇A股文献独立确认负向IC，A股散户结构放大彩票效应使该因子比美股更强。方向正确，horizon与系统2-4周窗口匹配，机构适配度中高。接入条件：(1) 必须分板块(主板/科创创业板/北交所/ST)标准化MAX上限，否则截面比较失效；(2) 必须做行业+市值双重中性化，防止因子实为小盘暴露；(3) 须有T+2延迟入仓机制避免连板动量干扰；(4) 首次接入建议低权重(confidence=0.75, base_weight=0.8)，通过PIT回测验证+10d/-10d相对IC后再定权；(5) 未来若同时接入LIMIT_FREQ，需降低两者权重防止双计。
