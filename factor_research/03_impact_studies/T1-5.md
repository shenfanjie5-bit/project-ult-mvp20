# T1-5 — 大宗交易折溢价 / 成交额占比（Block_Trade_Discount + Block_Trade_Ratio）

**裁决：CONDITIONAL** · 把握 med · 实施优先级 med

### 目标轴
capital_sentiment

### 系统已有?
none — block_trade 端点目前在系统内零覆盖。capital_sentiment 仅有 L7.flow.active_inflow（moneyflow.main_net → tanh）一个节点，block_trade 是完全独立的 tushare 端点，无任何 dp_id 路由。

### 正交性
正交性高。active_inflow 捕捉的是场内主力订单流（日内大单净额，moneyflow 接口），而大宗交易是交易所场外议价通道（协议转让），两者底层机制、时间颗粒度、参与者均不同：前者是日频散户/主力混合订单，后者是机构/大股东的整块转让意图。预期因子间相关性较低（大宗溢价买入不一定当日也产生大单净流入）。相对系统现有六轴，额外提供的是"离场机构愿意支付的价格溢价 / 机构配置活跃度"这一独立信息维度，不与 priced_in（场内 run_up/crowdedness）、valuation_rerating、fundamental 高度重叠。

### 双计风险
低-中。最需警惕的潜在双计是溢价大宗 → 股价已上涨 → run_up 也升 → priced_in_discount 同步升高。但 run_up 捕捉的是场内连续收盘价涨幅（d20_pct），而大宗溢价发生在场外、往往比场内价格提前或滞后，相关性并非机械。更大的去重风险：若同时接入 CNIR（主力净流入，因子族 #4）和 Block_Trade_Ratio，两者都是"资金流量类"，在行情好时可能同向放大 capital_sentiment；但在当前系统中 CNIR 尚未接入，不存在当前冗余。

### 方向
整体方向正确，但有重要限定：(1) 溢价方向（BT_Disc > 0）→ 买方主动付价 → 机构看多 → capital_sentiment + ，方向明确正确。(2) 折价方向（BT_Disc < 0）→ 理论是看空，但 A 股大宗折价中大量属于"过桥代持"（机构两端同时出现于买卖双方，折价无方向性信息），直接取负值接入 capital_sentiment 会引入噪声甚至误导。正确做法是：折价信号需过滤后单独接 risk_discount，而非直接接 capital_sentiment 负值。(3) BT_Ratio（成交额占比）→ 高占比 + 低波动率组合 → 建仓信号 → +capital_sentiment，方向正确；但单纯成交额占比（无波动率条件）有正向共模偏差（绝对量化），需行业内截面 rank 后使用。

### A股有效性/陷阱
实证支持有限但真实存在。光大证券量化选股系列报告11（2023）确认：高大宗成交额占比 + 低成交量波动率组合有显著超额收益；大宗溢价成交后超额收益明显，折价成交则信号混乱（过桥比例高）。独立因子 IC 约 0.02-0.03，弱但正向。主要陷阱：(a) 过桥污染——折价 ≥ 30% 案例中，买卖两端均为机构的过桥占比极高（金融界 2024 数据），折价不等于卖出信号；(b) 小市值噪声——大宗交易几乎不发生在小市值股，若不作市值中性化，信号稀疏股数量极少（全市场大宗活跃股约 300-500 只/月），覆盖率是系统瓶颈；(c) 涨跌停截断——涨跌停日收盘价异常，折溢价率计算基准失真，需过滤；(d) T+1——大宗交易完成后次日才能卖出，超短期信号须滞后 1TD；(e) 因子频率——block_trade 是事件触发型，数据稀疏，21TD 窗口才能积累足够样本，低于系统 2-4 周节奏。

### 周期契合
偏长，与系统 2-4 周核心窗契合度中等。因子目录中 Block_Trade_Ratio 周期标注 21-63TD、Block_Trade_Discount 标注 10-21TD 事件后效应。溢价大宗后价格效应：通常在 10-15TD 内最强，此后衰减，基本吻合 2-4 周窗口。但信号实际的"事件密度"很低（每股大宗交易频率不高），21TD 累积窗口是最低有效统计单位，5-10TD 窗口样本极少、噪声极大。结论：勉强可用于 2-4 周信号，但不是最锐利的短期因子；在 horizon mix 中建议降低其在短期（capital_sentiment 短权 0.40）内的有效信号权重，用低内部权重控制影响。

### 机构适配
高。大宗交易几乎只有机构/大股东参与，是 A 股"机构为主市场"中直接可观测的机构意图信号，适配度强于散户行为因子。溢价成交尤其是机构主动建仓的直接体现。对本系统"机构为主市场"定位契合度好。

### 接入设计
建议分拆为两个独立 dp_id，条件接入：

**dp_id 1：L7.block.premium_signal（新增）**
- 公式：BT_Disc_avg_t = Σ(BT_Disc × amount) / Σ(amount)，21TD 内所有成交笔；过滤过桥（买卖双方为同一机构的记录）；仅取正值（溢价）接入 capital_sentiment，折价置零（不接 capital_sentiment）
- score_target：capital_sentiment
- 行业中性化：是，行业内 rank 后 zscore
- 归一化：percentile → tanh(zscore)，输出 [0, +0.8] 单向正值（只有溢价端有效）
- 内部权重：0.2（capital_sentiment 当前仅 active_inflow，需保留 active_inflow 为主力；新节点作辅助）
- PIT 安全：block_trade.trade_date 即为信号日，PIT 安全；滞后 1TD 实施（T+1 约束）；涨跌停日剔除

**dp_id 2：L7.block.ratio_signal（新增，条件接入）**
- 公式：BT_Ratio_21 = Σ block_trade.amount_{t-21..t} / Σ daily.amount_{t-21..t}；行业内 percentile rank；附加条件：BT_VolStd（成交量波动率，std/mean）需在行业中位以下（筛选建仓特征，非减仓/过桥特征）
- score_target：capital_sentiment
- 行业中性化：是（先 rank 再归一）
- 归一化：percentile → 线性映射 [0, +0.6]（去掉高 volstd 后的条件化得分）
- 内部权重：0.15
- PIT 安全：daily.amount PIT 安全，block_trade.trade_date 为事件日，无前视；剔除小市值（流通市值 < 20 亿）防稀疏噪声

总体 capital_sentiment 贡献上限：两个新节点合计权重 ≤ 0.35，active_inflow 保留权重 ≥ 0.65（防止稀疏的大宗信号压过持续日频的主力净流入）。

### 负面情形
1. 过桥污染导致折价信号方向错误：若不过滤过桥记录直接使用折价端，会在机构代持/融资操作时产生错误看空信号，为负面影响最大的失效模式。解决：折价端不接 capital_sentiment，单独评估是否接 risk_discount。
2. 稀疏覆盖拉低有效信号：全市场 90% 以上股票在单月内无大宗交易，空白节点（unknown/score=0）被跳过（覆盖率归一加权均值）不影响整体 capital_sentiment，但激活该因子的股票仅占少数，无法成为普适选股器，仅在 capital_sentiment 有正值时提供边际增量。
3. 涨跌停截断导致折溢价率基准失真：收盘价涨跌停时分母失真，折溢价率可达 ±10%+ 的极端值，需严格过滤。
4. 信号在 A 股政策行情（快速拉升）期间失效：政策市急拉时大宗交易滞后市场行情，折溢价信息滞后性导致信号失效或反向（买方已经错过最优时机）。
5. 小市值/科创/北交所覆盖极低：大宗交易机制对流通市值小的股票几乎无效，按建议作市值过滤后实际可用标的约 500-800 只，系统规模决定了这只能是补充信号。

### 裁决理由
大宗折溢价/成交额占比因子对 capital_sentiment 死轴有净增益，但必须满足三个前提条件才能接入：(1) 折价端必须隔离——不接 capital_sentiment，不接 risk_discount（需单独专项分析过桥过滤逻辑），仅溢价端 (BT_Disc > 0) 接入；(2) BT_Ratio 必须行业内截面 rank + 附加低成交量波动率条件，裸比率有正向共模；(3) 两个新节点合计权重 ≤ 0.35，保证 active_inflow 作为主力节点不被稀疏大宗信号稀释。满足上述条件后，溢价端 IC ≈ 0.02-0.03 叠加机构行为独特信息，对目前近乎空置的 capital_sentiment 轴是真实的净正向贡献，优先级属于"capital_sentiment 填充批次第一梯队（次于融资买入动量和 CNIR，因其覆盖率更高、IC 更稳）"。不满足条件则为 NEGATIVE（折价污染会让 capital_sentiment 在大量正常机构过桥操作时误判为看空）。
