# T4-1 — 行业内横截面 EP（盈利收益率·行业中性化 / EP_IndustryNeutral）

**裁决：NEGATIVE** · 把握 high · 实施优先级 low

### 目标轴
valuation_rerating

### 系统已有?
overlaps L6.state.peer_compare（R-3b.2 已横截面化：hierarchical pool 排 PE/PS → -(pct-0.5)*2，与 EP_IND 功能等价）+ L6.mult.forward_pe（前向 PE log-ratio，同类信号）+ L5.fina.net_profit_yoy（TTM 盈利已在 fundamental_score）

### 正交性
无新增正交信息。EP_IND = TTM净利润 / 市值，在行业内做 z-score → 与 peer_compare（已将 PE 在同类池排百分位，信号 = -(pct-0.5)*2）是同一事实的两种表达方式：两者均测量"同业中谁贵/便宜"，相关性 r > 0.90。与 fundamental_score 轴的 net_profit_yoy/ROE/ROA 中度相关（分子重叠）。相对现有六轴，EP_IND 不带来独立维度。

### 双计风险
高。双计风险有两层：①估值层——EP_IND 与 peer_compare(R-3b.2) 同时存在 valuation_rerating 桶，两者均用横截面 PE 排名，signal 几乎等价，会将同一事实放大约 2×；②盈利层——TTM 净利润已进入 L5.fina.net_profit_yoy（fundamental_score）和 L5.fina.roe，EP = 净利润 / 市值 与这两者部分线性相关，跨轴双计。R-3b.2 代码已明确：当 valuation pool 激活时，suppressed 清单包括 L6.mult.forward_pe / ps / ev_ebitda，但新引入的 EP_IND dp_id 不在 suppressed 名单，会 bypass 压制逻辑而叠加运行。

### 方向
方向正确（高 EP_IND → 同业便宜 → 看多 → 正值 → 提升 valuation_rerating 正向得分，对应减少 val_pressure 或增加正向贡献）。但在系统框架内，valuation_rerating 是"贵→减分"轴，peer_compare 已经承担这一职责，方向不需要从 EP_IND 重新引入。

### A股有效性/陷阱
月度 Rank IC 均值 4-5%，ICIR 1.6-2.0（国泰君安/源达/bigquant 2022-2025实证，申万二级行业中性化后）。陷阱清单：①负 PE 陷阱——A股10-15%股票净利润为负，负 EP 不处理会破坏单调性，需零截断+哑变量；②涨跌停截断——当日 PE 失真，须用 T-1 收盘价；③T+1 影响月度再平衡可忽略，但系统目标是 2-4周窗口，EP 信号在此频率 IC 低于月度约 20-30%；④ST 股须系统剔除（已有 st 端点）；⑤因子拥挤：2022-2024 机构大量使用行业中性EP，进入成长风格期间短暂失效；⑥财报 PIT——季报披露时点（Q1:4月底/半年报:8月底/Q3:10月底/年报:4月底），须严格用 disclosure_date 过滤防前视。

### 周期契合
弱-中等契合。EP 因子本身IC在1-3个月达峰，2-4周窗口IC约为月度的70%（仍正但略低）。系统已知的+10d rankIC=+0.113 是所有打分节点的综合，估值类节点在10d窗口权重仅0.10，贡献极小。horizon 不匹配会进一步稀释边际增量，这一点强化了"低优先级"判断。

### 机构适配
高适配度（机构选股 roadshow 用同业PE对比，行业中性EP直接对应机构相对配置视角）——但这一信息已经被 peer_compare(R-3b.2) 充分吸收，机构适配度不是新增EP_IND的理由。

### 接入设计
如果仍要接入（CONDITIONAL 条件下）：新建 dp_id = L6.ep.industry_neutral，score_target = valuation_rerating；公式：EP_raw = TTM净利润 / total_mv（daily_basic.pe_ttm 倒数），负净利润置0同时设D_loss哑变量；在申万二级行业（index_member_all）截面做 z-score，winsorize ±3σ；tanh 归一：score = tanh((EP_IND - 0) / 1.0) → 正值=便宜=正向 valuation_rerating；PIT：仅用 disclosure_date ≤ 计算日的财报；行业/市值中性化：行业内 z-score 已内含行业中性，无需再做市值中性（但需用中性化后的残差以避免小盘效应）；权重：valuation_rerating 轴 long horizon 0.30，短期 0.10；须与 L6.state.peer_compare 协调以防止双计——最简单的做法是将 EP_IND 纳入 _VALR_SUPPRESSED_WHEN_POOLED 名单，仅在无 valuation pool 时激活（作为 peer_compare 的降级替代，而非并列）。

### 负面情形
①与 peer_compare 并行运行：系统对"便宜股"打分约 2× 强化，导致估值轴失真放大，最终 valuation_rerating 对部分股票偏高（误触 BUY 阈值）；②负 EP 处理不当：亏损股 EP 大负值未零截断，IC 下降 0.5-1 pct，污染整个估值轴；③财报延迟未做 PIT：季报 disclosure_date 过滤疏漏导致前视偏差，尤其在 Q1/Q3 季报披露高峰期（4月/10月）；④成长风格切换：2022-2024 价值-成长轮动期，行业中性 EP 短暂失效，与 peer_compare 同时失效形成双重打击（无多样化）；⑤行业分类粒度不足：若行业分类用申万一级而非二级，同行业内分散度过大，IC 下降。

### 裁决理由
EP_IndustryNeutral 在本系统中是冗余信号，而非新增正交信息。R-3b.2 已将 peer_compare 升级为分层池横截面 PE/PS 排名（F6 archetype → industry → market），其输出 -(pct-0.5)*2 与 EP_IND 的行业内 z-score 测量的是完全相同的事实——"同业中谁的市盈率更低"。两者并存将导致 valuation_rerating 轴对估值便宜股的分数被放大约2×（双计），破坏系统已经精心校准的 BUY/HOLD/WATCH/AVOID 阈值。如需接入EP类信号，正确路径是将 EP_IND 设为 peer_compare 在无 valuation pool 时的降级替代（纳入 _VALR_SUPPRESSED_WHEN_POOLED 名单），而非新增并行 dp_id。当前的资源投入应优先补充真正死轴（capital_sentiment/funding）和正交因子（momentum/reversal、低波动、SUE盈利惊喜），这些是系统清单 §E 明确标记的缺口，边际 IC 贡献远高于 EP_IND。
